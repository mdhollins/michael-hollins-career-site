# Michael Hollins Living Career Archive

Next.js source for the living career archive and multimedia professional portfolio.

## Local development

```bash
npm install
npm run dev
```

## Media

Career images live in `public/media/`. The first image set includes:
- Current UNMC/Davis Global Center portrait
- KANEKO: Design in Motion, WATER, Passion & Obsession, Reality, Google AI program
- PACE/Hoff Center: construction and design-phase images

## Vercel

This repository is intended to connect to the existing Vercel project `michael-hollins-career-site`.
Once GitHub is connected to that project, pushes to the production branch can trigger automatic deployments.
